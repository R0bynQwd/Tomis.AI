# 🏛️ TOMIS.AI - Cluster AI Hibrid, Portabil și Autonom

## 🚀 Prezentare
TOMIS.AI este un sistem de calcul distribuit conceput să transforme orice dispozitiv (Windows, Linux, Edge) într-un nod activ de procesare AI.

### ✨ Caracteristici Cheie:
- **Arhitectură Unificată:** Totul este gestionat prin 3 scripturi inteligente (.bat, .ps1, .sh).
- **Procesare Multi-Modală:** Whisper (ASR), OCR, Vision (YOLOv8), Voice Fingerprinting, NLP/RAG Românesc.
- **Stealth Orchestration:** Procesare activă doar în mod Screensaver (OLED Safe, Anti-Standby).
- **Consensus Engine:** Verificarea rezultatelor prin colaborarea între mai multe noduri.
- **Offline Ready:** Generare automată de kituri portabile pentru instalare fără internet.

## 🛠️ Instalare Rapidă
1. **Windows:** Rulează `Start-Deploy.bat` ca Administrator.
2. **Linux/Edge:** Rulează `sudo bash Start-Deploy.sh`.
